Password Reset Feature

User Story:
As a user, I want a password reset function so that I can recover my account if forgotten.

Requirements:
- User enters registered email.
- System sends a password reset request.
- User can create a new password.

Validation:
- Email must be registered.
- New password cannot be empty.
- New password must meet minimum security requirements.
- New password must be different from the old password.

Feature Flow:
1. User enters registered email.
2. System verifies that the email is registered.
3. System sends a password reset request.
4. User creates a new password.
5. System updates the user's password.

Documentation:
Password reset allows registered users to recover access to their account.
Users must provide a registered email and create a valid new password.
